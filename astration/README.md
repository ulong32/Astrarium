# Astration

Data extraction and synchronization pipeline for game assets, chart files, and master databases.

## Features

- **Master Data Synchronization**: Extract CDN download links from intercepted API requests and decode MasterMemory database tables into structured JSON.
- **Chart & Audio Pipeline**: Download encrypted rhythm game notations and audio bundles, decrypt AES-CBC payloads, decompress Brotli data, and convert CRI ACB audio into WAV format.
- **Unity Asset Extraction**: Unpack Unity Addressables bundles, extract textures (including ASTC to PNG decoding via `texture2ddecoder`), meshes, and audio assets.
- **Class Schema Extractor**: Parse `Il2CppDumper` output (`dump.cs`) to generate MessagePack object schemas.

---

## Prerequisites

- **Python**: 3.10 or higher
- **vgmstream** (Optional, for audio conversion):
  - Download `vgmstream-cli` from the official repository.
  - Ensure `vgmstream-cli` is added to your system `PATH`, or set `VGMSTREAM_PATH` in your environment.

### Installation

```bash
cd astration
python -m venv .venv
# On Windows (PowerShell):
.venv\Scripts\Activate.ps1
# On Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Configuration

Copy the sample environment file and configure your keys:

```bash
cp .env.example .env
```

| Variable            | Description                                         |
| ------------------- | --------------------------------------------------- |
| `ASSET_SERVER_URL`  | Base URL for asset CDN (e.g. `https://example.com`) |
| `TARGET_ASSET_HOST` | Hostname filter for mitmproxy intercept scripts     |
| `KEY_CONFIG`        | AES-CBC key used to decrypt `music_config` files    |
| `KEY_NOTATION`      | AES-CBC key used to decrypt rhythm chart notations  |
| `VGMSTREAM_PATH`    | Optional explicit path to `vgmstream-cli.exe`       |

## CLI Usage

Run the main pipeline dispatcher:

```bash
python __main__.py --help
```

### Subcommands

#### 1. Full Pipeline (`run-all`)

Runs `update-master`, `parse-master`, and `sync-assets` in sequence:

```bash
python __main__.py run-all <path_to_intercepted_bin> --version 1.96.0
```

#### 2. Update Master DB (`update-master`)

Extracts the database download URL from an intercepted MessagePack request binary and downloads the file:

```bash
python __main__.py update-master <path_to_api_data_master.bin>
```

#### 3. Parse MasterMemory (`parse-master`)

Decodes the MasterMemory SQLite DB into JSON tables under `mastermemory_tables_decoded/`:

```bash
python __main__.py parse-master <path_to_db_file>
```

#### 4. Sync Music & Charts (`sync-assets`)

Downloads encrypted chart notations and music bundles:

```bash
python __main__.py sync-assets --master mastermemory_tables_decoded/MusicMaster.json --version 1.96.0
```

#### 5. Sync Catalog Bundles (`sync-catalog`)

Downloads Unity Addressables bundles:

```bash
python __main__.py sync-catalog 2d-assets --version 1.96.0 --limit 100
```

#### 6. Extract Unity Bundles (`extract-bundles`)

Extracts assets from downloaded `.bundle` files:

```bash
python __main__.py extract-bundles <input_bundle_dir> --output_dir extracted_assets --audio-format wav
```

#### 7. Decode ASTC Textures (`extract-astc`)

Converts raw `.astc` files into PNG:

```bash
python __main__.py extract-astc <input_dir> --output_dir extracted_pngs
```

#### 8. Extract MessagePack Schemas

Parse `dump.cs` generated by Il2CppDumper to extract MessagePack models:

```bash
python scripts/extract_msgpack_classes.py --dump-cs /path/to/dump.cs --output schemas/msgpack_classes.txt
```
